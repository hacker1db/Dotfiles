This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic detail and creative intentionality.

## Design Thinking (Do This Before Coding)

1. **Purpose** — what problem does this solve? Who uses it?
2. **Tone** — commit to a BOLD aesthetic direction: brutally minimal, maximalist, retro-futuristic, organic, luxury, brutalist, editorial, etc.
3. **Differentiation** — what makes this unforgettable?

## Implementation Requirements

- Production-grade and functional
- Visually striking with a clear aesthetic point-of-view
- Meticulous in typography, color, motion, and spatial composition
- NEVER use generic aesthetics: Inter/Roboto/Arial, purple-gradients-on-white, cookie-cutter layouts

**Match complexity to vision**: maximalist designs need elaborate animations; minimalist designs need precision and restraint.

See `references/aesthetics-guide.md` for detailed typography, color, motion, and background guidelines.
