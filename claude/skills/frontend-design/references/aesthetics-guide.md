# Frontend Design — Aesthetics Guide

## Typography

Choose fonts that are beautiful, unique, and interesting. Avoid generic fonts (Arial, Inter, Roboto, system fonts). Use unexpected, characterful choices that elevate the design. Pair a distinctive display font with a refined body font.

Good directions: editorial serif pairings, condensed display fonts, geometric sans-serifs with personality, historical revivals, monospace hybrids.

NEVER default to Inter, Space Grotesk, or other overused "dev aesthetic" fonts.

## Color & Theme

Commit to a cohesive palette. Use CSS variables for consistency. Dominant colors with sharp accents outperform timid, evenly-distributed palettes. Light AND dark themes are both valid — vary by project.

Avoid: purple gradients on white, teal/coral combos, generic "startup blue."

## Motion & Animation

Use CSS-only solutions for HTML artifacts. Use the Motion library for React when available. Focus on high-impact moments: one well-orchestrated page load with staggered reveals creates more delight than scattered micro-interactions. Scroll-triggering and hover states that surprise.

Match intensity to the aesthetic — maximalist designs deserve elaborate animations; minimalist designs deserve subtlety.

## Spatial Composition

Unexpected layouts: asymmetry, overlap, diagonal flow, grid-breaking elements, generous negative space OR controlled density. Don't default to centered hero + three-column features.

## Backgrounds & Visual Details

Create atmosphere and depth:
- Gradient meshes, noise textures, geometric patterns
- Layered transparencies, dramatic shadows
- Decorative borders, custom cursors, grain overlays
- Contextual effects that match the overall aesthetic

Avoid flat solid-color backgrounds unless the aesthetic demands it.

## Aesthetic Directions (pick one and commit)

- **Brutally minimal** — ruthless whitespace, one typeface, one color, nothing decorative
- **Maximalist chaos** — overlapping elements, many colors, dense information
- **Retro-futuristic** — CRT effects, scan lines, neon on dark, terminal aesthetics
- **Organic/natural** — soft curves, earthy tones, biomorphic shapes
- **Luxury/refined** — gold accents, serif typography, restrained palette
- **Playful/toy-like** — rounded corners, bright primaries, hand-drawn elements
- **Editorial/magazine** — bold headers, photo-centric, grid-based layouts
- **Brutalist/raw** — exposed structure, system fonts ironically, no decoration
- **Art deco/geometric** — symmetry, metallic tones, angular ornament
- **Industrial/utilitarian** — monospace, grids, functional over aesthetic

Vary between these across projects — no two designs should converge on the same choices.
