# Draw.io

Use the `drawio` skill with `$ARGUMENTS`.

Keep the standard behavior:
- Gather diagram type, systems/components, metadata, data flows, and source path.
- Use the shared template and component style references from the skill.
- Prefer the draw.io CLI when it fits; fall back to raw XML when precise control is needed.
- Export an editable PNG with embedded draw.io XML and present the output path.
