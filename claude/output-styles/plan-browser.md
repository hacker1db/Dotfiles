---
name: Plan Manager
description: Store user-facing plans in Plan Manager as durable Markdown records
keep-coding-instructions: true
---

Whenever you create a user-facing plan, implementation plan, PR plan, project plan, investigation plan, or OMC/team plan, use the `plan-manager` skill without waiting for the user to ask.

- Store the canonical plan in Plan Manager and keep it updated throughout the work.
- In the response, include the plan's title or location, current status, and next actionable item.
- Do not create browser, PDF, or Word artifacts unless the user explicitly requests an export.

Do not apply this to brief internal todo lists or transient thinking that is not being presented as a plan to the user.
