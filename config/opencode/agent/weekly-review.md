# Weekly Review

Automated weekly review and planning workflow (GTD-inspired).

## Command

### /weekly-review

Generate a comprehensive weekly review analyzing your week's activity, progress, and planning next week.

**What it does:**
1. **Inbox Processing**: Reviews `0.Quick Notes 📨/0. Inbox Notes.md`
2. **Goal Progress**: Checks `1.Projects/Yearly Goals Dashboard 🥅.md`
3. **Journal Analysis**: Summarizes `2.Areas/Personal Home/Journal/` entries from past 7 days
4. **Work Notes**: Highlights from `2.Areas/Work Notes/DevSecOps Notes/`
5. **Readwise Digest**: Recent highlights (if API key configured)
6. **CVE Monitoring**: Critical vulnerabilities from past week
7. **Blog Posts**: Drafts in progress, publication status
8. **Next Week Planning**: Action items and priorities

## Usage

```
/weekly-review
```

Typically run on **Friday afternoon** or **Sunday evening**.

## Research Sources

The command analyzes:

**Primary Sources:**
- `0.Quick Notes 📨/0. Inbox Notes.md`
- `1.Projects/Yearly Goals Dashboard 🥅.md`
- `1.Projects/Tasks.md`
- `2.Areas/Personal Home/Journal/` (past 7 days)
- `2.Areas/Work Notes/DevSecOps Notes/` (past 7 days)
- `2.Areas/Personal Home/Blog Posts 🕸/` (draft status)

**Optional (if configured):**
- Readwise highlights (past 7 days)
- NVD CVEs (past 7 days, CVSS >= 8.0)

## Workflow Integration

### Friday Afternoon Review
```
1. /weekly-review
   → Generates comprehensive review

2. Review in Obsidian
   → Reflect on week
   → Adjust priorities

3. /inbox-process
   → Clear inbox items

4. Plan next week's blog content
   → /blogresearcher [topic from priorities]
```

### Monthly Stack
```
Week 1: /weekly-review
Week 2: /weekly-review
Week 3: /weekly-review
Week 4: /weekly-review + /monthly-reflection
```

## Configuration

**Journal Path:**
Default: `2.Areas/Personal Home/Journal/`

**Output Path:**
Default: `2.Areas/Personal Home/Weekly Reviews/`
(Creates folder if it doesn't exist)

**Date Range:**
Default: Past 7 days from command execution
Override: `/weekly-review start=2025-01-15 end=2025-01-21`

## Tips

1. **Consistency**: Run same day/time each week (Friday 4pm, Sunday 7pm)
2. **Review Before Planning**: Read the review before setting next week's priorities
3. **Track Themes**: Look for recurring patterns in "Patterns Noticed" section
4. **Archive**: Keep all weekly reviews for quarterly/yearly analysis
5. **Adjust Format**: Edit template in `.opencode/brand/weekly-review-template.md`
