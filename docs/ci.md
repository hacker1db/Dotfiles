# CI and security scanning

`.github/workflows/ci.yml` runs on pushes to `main` and on pull requests: `zsh -n` over `install.sh`, `install/*.zsh`, the Zsh configuration, and every Zsh script in `bin/` and the Git hooks; ShellCheck at warning severity over the Bash and POSIX shell scripts in `bin/`, the Git hooks, and the SketchyBar plugins; `ruby -c` over `bin/gbrt`; plus Luacheck over the Neovim config (ignoring existing unused-variable and line-length warnings). A `secrets` job runs [betterleaks](https://github.com/betterleaks/betterleaks) (MIT, no account or API key) from its `ghcr.io` image, pinned to v1.10.1 by digest, with no network and a read-only checkout, over the commits a pull request adds (base to head) or a push adds (before to after), not the full history, and fails on any detected secret. Handle false alarms with a `betterleaks:allow` comment on the line or a fingerprint in `.betterleaksignore`, reviewed in the PR. On pull requests, dependency review fails if a change adds a dependency with a known vulnerability of any severity.

`.github/workflows/codeql.yml` runs CodeQL `security-extended` queries for GitHub Actions and JavaScript/TypeScript on pushes to `main`, on pull requests, and weekly. `.github/dependabot.yml` opens update pull requests for npm, Docker, and pinned GitHub Actions. Every action is pinned to a commit SHA.
