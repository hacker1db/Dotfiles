# CI and security scanning

`.github/workflows/ci.yml` runs on pushes to `main` and on pull requests: `zsh -n` over `install.sh`, `install/*.zsh`, the Zsh configuration, and every Zsh script in `bin/` and the Git hooks; ShellCheck at warning severity over the Bash and POSIX shell scripts in `bin/`, the Git hooks, and the SketchyBar plugins; `ruby -c` over `bin/gbrt`; plus Luacheck over the Neovim config (ignoring existing unused-variable and line-length warnings). A `secrets` job runs the GitGuardian `ggshield` action, pinned to a commit SHA, over the commits a pull request adds (base to head) or a push adds (before to after), not the full history, and fails on any detected secret. It needs a GitGuardian API key in the `GITGUARDIAN_API_KEY` repository secret. Handle false alarms with a `.gitguardian.yaml` ignore entry reviewed in the PR, or by ignoring the incident in the GitGuardian dashboard. On pull requests, dependency review fails if a change adds a dependency with a known vulnerability of any severity.

`.github/workflows/codeql.yml` runs CodeQL `security-extended` queries for GitHub Actions and JavaScript/TypeScript on pushes to `main`, on pull requests, and weekly. `.github/dependabot.yml` opens update pull requests for npm, Docker, and pinned GitHub Actions. Every action is pinned to a commit SHA.
